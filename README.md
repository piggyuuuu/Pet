# XXpet —— xx宠物跨平台复刻版（深度定制增强版）

> 本项目基于 [AnkioTomas](https://github.com/AnkioTomas) 的 **QQPet**（xx宠物跨平台复刻版，基于 Arctic Penguin T800 逆向重建）二次开发，独立命名为 **XXpet**。
> 原作者及版权归属 AnkioTomas（GPL-3.0）。本仓库为**在原版基础上的功能增强与定制更新**，不包含原作者的原始源码仓库（已不可访问），仅提供修改后的运行产物与说明。

## 项目简介

XXpet 是 xx宠物（QQPet/QQPets）的跨平台复刻实现，使用 Electron + Ruffle（Flash 运行时）还原经典桌宠体验。本仓库在**原版功能完整保留**的前提下，加入了以下增强：

### 新增功能（基于原版的更新）

1. **双击宠物弹出 AI 对话气泡**
   - 双击宠物立即弹出气泡，宠物基于当前时间、心情、状态和当天事件主动说一句话
   - 气泡附带 3 个 AI 生成的口语化回复选项（自动限长避免溢出），点选即进入 AI 对话

2. **AI 对话系统增强**
   - 接入兼容 OpenAI 接口的自托管/本地大模型（模型地址与密钥在设置中配置，默认本地 `http://127.0.0.1:8000/v1`）
   - 宠物拥有完整人设画像（名字、等级、饱食/清洁/心情/健康、时间、今日事件），AI 回复更贴近宠物身份
   - 支持上下文记忆（最近对话历史 + 长期记忆持久化）
   - 聊天窗口内自动生成 3 个继续话题的候选选项
   - 随机气泡对话由 AI 原创生成，并感知主人当前正在使用的软件（`frontHint`）进行自然互动

3. **独立「Q币」货币系统**
   - 新增 Q币（`qb`）货币：渔场卖鱼赚 Q币、买鱼苗/喂鱼扣 Q币；农场收菜/购买同步 Q币
   - 粉钻、贴心宝贝等增值服务改用 Q币购买（300 Q币/天）
   - 宠物档案面板显示当前 Q币余额
   - 渔场/农场 SWF 内所有「元宝」提示文案已替换为「Q币」

4. **心情系统优化**
   - 互动/逗弄/聊天每次增加心情值大幅提升（约 4~5 次互动即可加满）
   - 心情自然衰减速度降为原版的 20%，宠物更容易保持好心情

5. **自动更新指向本仓库**
   - 版本检测 API 与内容包地址已改为本仓库（piggyuuuu/Pet），应用内「检查更新」将直接跳转本仓库的 Release 下载页

## 目录结构

```
XXpet/
├── out/                    # 编译产物（Electron 主进程 + 渲染进程）
│   ├── main/               # 主进程代码
│   ├── preload/            # 预加载脚本
│   └── renderer/           # 渲染进程（含 Ruffle Flash 播放器）
├── package.json
└── README.md
```

> 说明：原始源码（TypeScript/构建源）随原作者仓库不可访问而不可得，本仓库保存的是**已修改的应用包内容**（`out/` 编译产物），可在 `npm install` 后通过 Electron 直接加载运行。SWF 资源（宠物动画、气泡、农场/渔场）位于应用 resources 目录，未随本仓库分发，需从原版安装目录获取或自行替换。

## 运行方式

```bash
npm install
npx electron .
```

应用存档位置继承自原版（`%APPDATA%/QQPet/save.json`，不在本仓库内）。AI 对话需在设置页填写 `AI 地址 / Key / 模型`（或本地启动一个 OpenAI 兼容服务）。
